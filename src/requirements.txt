# Análisis de Datos - PROYECTO_MITIC  

## Carga y Preparación de Datos  
Para la manipulación y análisis de datos, se emplean las bibliotecas Pandas, Seaborn y Matplotlib. Los datos se importan desde un archivo CSV y se realiza una reestructuración del conjunto de datos para mejorar su comprensión y facilidad de uso.  

### Optimización aplicada:  
- Uso de `pandas.read_csv()` para una carga eficiente de datos.  
- Renombrado de columnas para garantizar claridad y coherencia.  
- Exploración inicial para la detección de valores nulos o inconsistencias.  

---

## Exploración y Análisis de Datos  
Se lleva a cabo un análisis detallado de las características principales del conjunto de datos, incluyendo:  

- Total de pedidos procesados.  
- Distribución de ventas por ciudad y tipo de producto.  
- Identificación de patrones de compra según hora y mes.  

### Optimización aplicada:  
- Uso de `describe()` para obtener estadísticas clave de manera rápida.  
- Análisis de variables categóricas y numéricas mediante visualizaciones optimizadas.  

---

## Visualización de Datos y Patrones  
Para detectar tendencias y facilitar la interpretación de los datos, se generan gráficos optimizados de alto rendimiento:  

- Gráficos de barras para visualizar las ventas totales por ciudad.  
- Gráficos de líneas para analizar el comportamiento de compra según horas y meses.  
- Mapas de calor para identificar correlaciones entre variables.  

### Optimización aplicada:  
- Uso de Seaborn para una representación visual más eficiente y estilizada.  
- Configuración de Matplotlib para asegurar rapidez y calidad en la generación de gráficos.
